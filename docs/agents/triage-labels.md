# Triage Labels

State slice: `agent-skills-repository-routing-configuration`.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an agent to pick up |
| `ready-for-human` | `ready-for-human` | Human implementation or judgment required |
| `wontfix` | `wontfix` | Will not be actioned |

Applying `ready-for-agent` means the issue contains bounded scope, explicit
non-goals, acceptance tests, and enough repository context to execute without
inventing authority. It does not raise the evidence or capability ceiling.
