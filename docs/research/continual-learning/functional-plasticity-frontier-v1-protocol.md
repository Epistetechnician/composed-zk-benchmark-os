## Purpose and causal theory

The closed plasticity-guard, plasticity-recovery, equal-budget-selection, and
recursive-update-policy slices tested update admission, recovery, selection,
or policy recursion. This is a new exact-synthetic slice. It does not repair,
reopen, or use those slices as scientific inputs.

The theory is **functional plasticity preservation**:

> An update can preserve the learner's ability to acquire a fresh function
> when its parameter change is projected away from the span of protected
> function evaluations. Parameter-space safety alone is not the target. The
> target is the post-adaptation gain from one fixed update on a disjoint fresh
> task.

The causal treatment is the update rule. The protected-function projection is
fixed before execution and is computed from the protected feature functions.
There is no learned controller, adaptive threshold, wave schedule, memory
promotion, model, corpus, provider, or external truth oracle in this slice.

## Learner and function space

The learner has dimension `8` and parameter state `theta`, initialized to the
all-zero vector. Its function is:

```text
f_theta(x) = sum_i theta_i * x_i
loss(theta, x, y) = (f_theta(x) - y)^2
```

All values are finite IEEE-754 binary64 Python floats. A feature vector is
generated by the exact SHA-256 unit function below and then L2-normalized:

```text
u(parts) = int.from_bytes(sha256("|".join(str(part) for part in parts).utf8)[:8], "big") / 2**64
s(parts) = 2*u(parts) - 1
raw_i(seed, split, index, component) =
    s(state_slice, "feature", seed, split, index, component)
x = raw / sqrt(sum(raw_i**2))
```

The target is generated mechanically without external data:

```text
target_theta_i(seed, split) =
    0.31 * s(state_slice, "target-theta", seed, split, i)
y(seed, split, index) = dot(target_theta(seed, split), x(seed, split, index))
                         + 0.025 * s(state_slice, "target-noise", seed, split, index)
```

## Candidate update rules

For a fit shard `(x, y)`, learning rate `0.18`, and current state `theta`:

```text
raw_delta = 0.18 * (y - dot(theta, x)) * x
```

The protected function basis is the deterministic Gram-Schmidt orthonormal
basis of the eight protected feature vectors in index order. The projection is

```text
projected_delta = raw_delta
for q in protected_basis:
    projected_delta = projected_delta - dot(projected_delta, q) * q
```

Gram-Schmidt appends a normalized residual only when its L2 norm is strictly
greater than `1e-12`; a zero-norm feature or an empty protected basis is a
terminal generator failure. The fit-order digest is the canonical digest of
`{"case_index":case_index,"fit_indices":ordered_fit_indices}`.

The three arms are:

```text
untouched_base:      compute both candidate deltas and metrics, commit zero
fixed_adapter:       compute both candidate deltas and metrics, commit raw_delta
function_projected:  compute both candidate deltas and metrics, commit projected_delta
```

Each arm starts from the same immutable base state and processes the same
ordered fit shards. The projected arm is the sole treatment. There is no
parameter or threshold selection.

For every fit shard and every arm, both candidate states are evaluated on the
current fit shard and the protected suite before the arm-specific state is
committed. Thus every case and arm performs exactly:

```text
fit_shards:                    12
candidate_states:              24
candidate_fit_evaluations:     24
candidate_protected_evaluations: 24
committed_updates:              0 or 12, fixed by arm
```

The validator treats the first four counts as the compute budget. Commit count
is reported but cannot create a compute advantage.

## Endpoints and estimands

After all fit shards, define the fresh-task plasticity gain for arm `a` and
case `c` using every probe shard. A probe update is fixed for all arms:

```text
probe_delta = 0.22 * (y - dot(theta, x)) * x
P(c, a) = mean_probe[loss(theta, x, y)
                      - loss(theta + probe_delta, x, y)]
```

Positive `P` means the post-adaptation learner improves on the fresh task from
one fixed update. The primary case contrast is:

```text
D_FP(c) = P(c, function_projected) - P(c, fixed_adapter)
G_FP = mean_c D_FP(c)
```

The primary endpoint is `P`; `G_FP` is the preregistered treatment effect.
The untouched arm supplies the absolute reference `P(c, untouched_base)`.
Secondary outcomes are fit adaptation gain `A`, tune gain `T`, assessment
generalization gain `H`, protected forgetting `R`, and function-preservation
error `Q`:

```text
A(c, a) = mean_fit[loss(base_theta, x, y) - loss(theta_after_fit, x, y)]
T(c, a) = mean_tune[loss(base_theta, x, y) - loss(theta_after_fit, x, y)]
H(c, a) = mean_assessment[loss(base_theta, x, y)
                          - loss(theta_after_fit, x, y)]
R(c, a) = max(0, mean_protected[loss(theta_after_fit, x, y)]
                  - mean_protected[loss(base_theta, x, y)])
Q(c, a) = max_protected |dot(x, theta_after_fit - base_theta)|
```

The assessment digest is the canonical digest of
`{"case_index":case_index,"split":"assessment","gain":H}`. The probe
digest is the canonical digest of
`{"case_index":case_index,"split":"probe","gain":P}`. Each entry in
`fit_candidate_digests` is, in fit-order and candidate order (`raw`,
`projected`), the canonical digest of
`{"case_index":case_index,"fit_index":fit_index,"candidate":candidate,
"fit_loss":fit_loss,"protected_loss":protected_loss}`. These digests bind
the scalar candidate evaluations without retaining raw vectors.

The fixed decision rule requires all of:

```text
mean(G_FP) >= 0.0020
deterministic 95% bootstrap lower bound for mean(G_FP) >= 0.0000
function_projected beats fixed_adapter in at least 20 of 32 cases
mean(P(function_projected) - P(untouched_base)) >= -0.0020
all hard guards pass
```

The bootstrap uses `random.Random(73001)`, exactly 10,000 replicates, exactly
32 draws per replicate using `randrange(32)` in case index order, arithmetic
means, sorted replicate means, and linear interpolation at positions
`0.025 * (n - 1)` and `0.975 * (n - 1)`. The case is the resampling unit.
Token-, coordinate-, and shard-level resampling is forbidden. No formal power
claim is made; the effect threshold is a fixed practical threshold declared
before execution.

## Hard guards

The following are hard guards, not tunable endpoints:

```text
function_projected R <= 0.0500
function_projected P >= -0.0200
function_projected Q <= 1e-10
all control-arm R, P, and Q values finite
rollback max absolute state error <= 1e-12
compute counts equal the exact values above
forward/reverse paired delta for each arm <= 0.1000
base-state digest is identical in every case and arm
all values finite and all case/arm cells present exactly once
event chain is contiguous and ordered
independent validator passes
```

The order delta is the maximum of the absolute forward/reverse differences
for `A`, `T`, `H`, `P`, and `R`, paired by replicate seed and order seed. A missing
pair is a terminal failure.
