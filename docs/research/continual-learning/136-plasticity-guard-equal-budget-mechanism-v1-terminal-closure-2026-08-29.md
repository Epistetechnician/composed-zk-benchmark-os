## Material rejection findings

The reviewer found the equal-budget causal theory and three-arm mechanism
contrast coherent, but rejected the protocol because these executable defects
remained:

1. The corpus manifest required `source_id` without defining its identity or
   relation to `document_id`; tokenizer file identity and tokenizer-manifest
   schema were not exact.
2. The 100,000-replicate power simulation did not specify a reproducible normal
   sampler or transformation, and reliability terms did not define stable
   selection logs or complete adapter files.
3. Qualification named an exact probe sequence length without fixing the value
   or probe-token construction, so the shape and probe identity were not
   independently executable.
4. Configuration-digest construction and binding were incomplete; the runner
   interface did not provide a configuration-digest contract.
5. The pre-assessment review receipt lacked an exact schema, unknown-key rule,
   receipt digest, file identity, and invocation contract.
6. Validator aggregate-receipt transport, event payload/hash construction, and
   complete root-file closure were under-specified.
7. Cleanup command, cleanup target manifest, and executable credential and
   environment redaction were not defined.
8. The verification command invoked an undeclared `contract-check` mode, and
   the `full` mode depended on an unspecified authorization record.

These are protocol defects only. No scientific result, positive or negative,
may be inferred from this rejected slice. The prior plasticity-guard result
remains bounded feasibility evidence and is not upgraded by this design.
