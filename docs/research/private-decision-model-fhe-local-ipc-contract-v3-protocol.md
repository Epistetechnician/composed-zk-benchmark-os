State slices: `private-decision-model-fhe-local-ipc-contract-v3` and
`global-experiment-assurance-lifecycle-v1`. Frozen dependency slice:
`private-decision-model-fhe-inference-v1`. V2 is terminally closed as

## Purpose and claim ceiling

This fresh, local-only slice corrects and qualifies the fixed-shape JSON and
Base64 parser at the synthetic FHE client/server process boundary. It reuses
only the frozen V1 scorer, deterministic synthetic fixture, dependency lock,
and Concrete runtime identity. The failed V2 test result is retained only as a
failure record; no V2 output or model result exists to reuse.

The maximum claim is
`LocalDevelopmentSyntheticFHEIPCContractQualificationV3`: the exact V3 parser
rejects malformed and ambiguous IPC envelopes, and one bounded local FHE run
preserves the frozen synthetic scores and top rankings. This does not establish
cryptographic security, hostile-process isolation, remote-service behavior,
real-data utility, benchmark validity, or production readiness. No external
review or transfer is part of this slice. Reviewer status remains
`EXTERNAL_REVIEW_UNAVAILABLE` for the separate V1 review packet.

## Frozen question and hypothesis

Does a strict root-object JSON parser, closed-world request and response
schemas, and canonical non-empty standard Base64 validation reject every
predeclared malformed synthetic envelope before deserialization, while
accepting the exact V1 synthetic workload?

The hypothesis is that requiring an object at the JSON root closes the V2
control gap while preserving all fixed V1 encrypted scores and rankings. V1
source, scorer, fixture, dependency lock, and claim ceiling remain unchanged.

## Workload, budgets, and custody

- Data: the V1 deterministic synthetic fixture only; no user, external, or
  held-out research data. Its seed, shape, values, and digest are fixed by the
  V1 source and recorded in the V3 packet.
- Shapes: eight evaluation requests; four options per request; six signed
  integer features per option in `[-8, 8]`; 128 training rows and 12
  calibration requests remain unchanged.
- Focused checks: local parser tests over fixed literal envelopes, including
  duplicate keys at all object depths, malformed JSON, non-standard
  constants, and JSON roots that decode to arrays, strings, numbers, booleans,
  or null. Positive controls cover exact canonical request and response
  objects.
- FHE qualification: at most one local end-to-end run and at most eight
  encrypted request tensors. The worker may be invoked once for client
  specifications, once for evaluation, and once for a malformed-envelope
  parser control that must fail before bundle loading. Worker timeout is 900
  seconds; the parser-only subprocess timeout is 30 seconds.
- Runtime: use only the frozen V1 locked Python 3.12 environment and exact
  Concrete, NumPy, and PyTorch distributions. Dependency setup is offline
  against the already available locked cache; no network or provider access.
- Spend and transport: no provider, remote worker, network service, paid
  execution, review task, secure-channel transfer, or public service.
- Custody: synthetic inputs, keys, circuit bundle, serialized ciphertexts,
  responses, and arrays exist only in process memory or a system temporary
  directory and are removed at completion. Retain aggregate counts, digests,
  and pass/fail receipts only; do not retain raw IPC envelopes.

## Fixed contract and controls

The V3 JSON loader accepts only a JSON object at its root. It rejects duplicate
keys at every object depth and rejects non-standard JSON constants. Arrays and
scalars remain valid JSON values when nested under an object field where the
schema permits them.

The worker request has exactly `evaluation_keys` and
`encrypted_arguments`. The request carries one non-empty canonical Base64
evaluation-key string and exactly eight non-empty canonical Base64 argument
strings. The worker response has exactly `encrypted_results` containing eight
non-empty canonical Base64 strings. Missing, extra, duplicate, mistyped,
empty, malformed, and non-canonical fields fail closed.

Positive controls use the canonical envelopes generated by the local runner.
Negative controls cover duplicate root and nested keys; malformed JSON;
non-standard constants; array, string, numeric, boolean, and null roots;
missing and extra fields; incorrect types and counts; empty strings; invalid
Base64; and non-canonical pad bits. A subprocess control proves malformed
input is rejected before server-bundle loading and writes nothing to stdout.
The single FHE run compares all 32 encrypted scores and all eight top-ranked
options against the unchanged clear V1 scorer.

## Stop conditions and nonclaims

Any parser control failure, frozen V1 digest drift, score or ranking mismatch,
timeout, or failed temporary-artifact cleanup terminally closes V3. Do not
retune a control or rerun changed source under the V3 packet. No external
review, secure transfer, real or user data, remote service, paid run, public
release, or claim above the stated ceiling is authorized.

V3 does not revise or promote V1, reopen V2, or establish cryptographic
security, model-weight privacy, malicious-server integrity, remote deployment,
benchmark performance, commercial readiness, or production authorization.
Any later source, parser semantic, runtime, scorer, fixture, or claim change
requires another fresh state slice and packet.
