## Project Thesis

Test whether privileged mechanistic telemetry can help an observer model predict
causal intervention outcomes on a frozen actor, and whether those predictions
can improve later behavior without sacrificing calibration or safety.

The working name "astral self-modeling" describes the actor-observer separation.
It does not imply consciousness, subjective experience, literal self-knowledge,
or a reliable view of a model's complete computation.

## Primary Research Question

Can a preregistered estimator predict directly measured intervention effects on
held-out actor seeds and prompt families better than activation-only, text-only,
and capacity-matched controls? Only after that measurement gate passes may the
project test whether privileged telemetry adds observer value or supports
correction.

## Contributions Under Test

1. A supervision target derived from externally traced features, connections,
   attributions, and intervention effects.
2. A causal self-modeling objective that separates feature, graph,
   counterfactual, calibration, and downstream-improvement terms.
3. An actor-observer-tracer architecture with explicit telemetry boundaries.
4. An evaluation loop that distinguishes task performance, causal fidelity,
   calibration, and instrumental improvement.
5. An external-internal comparison that tests privileged access rather than
   presuming introspection.

These are candidate contributions. Novelty is unestablished until the literature
review and experiments rule out equivalent prior work.

## Claim Boundary

- A tracer output is an approximate measurement, not causal ground truth.
- A verbal mechanism description is not evidence of faithful computation.
- Better intervention prediction would establish task-scoped causal fidelity,
  not complete mechanistic understanding.
- Better self-correction would establish an instrumental effect in the tested
  setting, not general self-understanding.
- No result in this project establishes consciousness, sentience, agency,
  identity, global introspection, semantic correctness, or safety.
- Local experiments remain local regression evidence and do not alter accepted
  Evidence Ledgers or benchmark claims elsewhere in this repository.

## Decision and Reproducibility Policy

Material design decisions must be recorded in the relevant protocol or roadmap
with a date, rationale, alternatives, and reversal condition. Experimental runs
must pin model/checkpoint, code revision, dataset version and license, tracer
configuration, feature dictionary, seeds, hardware, and intervention definitions.
Reports must retain aggregate metrics, uncertainty, failures, exclusions,
configuration hashes, and artifact digests. Raw prompts, activations, and model
outputs require an explicit retention and privacy decision before collection.
