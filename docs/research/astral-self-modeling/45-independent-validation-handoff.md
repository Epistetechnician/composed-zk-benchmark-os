# Independent Validation Handoff

State slice: `astral-immutable-validation-release-v1`.

No author, author-controlled agent, or reused author implementation counts as
an independent reviewer or independent replication.

## Reproducibility reviewer

Required reviewer: a person not involved in implementing V1-V23.

Required actions:

1. obtain the immutable commit and content-addressed package;
2. verify package and commit identities independently;
3. run the authoritative validator in a clean environment;
4. inspect failures, exclusions, and assessment-absence assertions;
5. record environment differences and any author assistance;
6. sign the completed decision with an identity-bearing mechanism.

Decision fields, all required:

- reviewer name and affiliation: `UNFILLED`;
- conflict disclosure: `UNFILLED`;
- commit identity: `UNFILLED`;
- package identity: `UNFILLED`;
- report SHA-256: `UNFILLED`;
- result: `UNFILLED`;
- findings: `UNFILLED`;
- signature and timestamp: `UNFILLED`.

An unfilled form is `NotRun`, never acceptance.

## Scientific reviewer

Required reviewer: a person with no implementation role in V1-V23.

Required actions:

1. audit the preregistration chronology and assessment sealing;
2. inspect corpus overlap, label leakage, control strength, selection rules,
   uncertainty, and calibration;
3. verify every claim-ledger disposition against retained evidence;
4. review the V21 recovery event and V23 pre-sweep defect;
5. identify which claims are refuted, merely not refuted, or untested;
6. sign a zero-finding or finding-bearing report.

Decision fields, all required:

- reviewer name and affiliation: `UNFILLED`;
- conflict disclosure: `UNFILLED`;
- commit and package identities: `UNFILLED`;
- result: `UNFILLED`;
- claim corrections: `UNFILLED`;
- findings: `UNFILLED`;
- signature and timestamp: `UNFILLED`.

## Independent implementation replication

The independent operator must not import the Astral harness or copy its
implementation. The operator must preregister:

- a fresh eligible model checkpoint;
- a fresh corpus and sealed assessment;
- an independently written intervention instrument;
- text-only, activation-only, shuffled, cross-model, and anomaly-location
  controls;
- prediction/configuration locking before assessment;
- calibration and uncertainty gates;
- a claim ceiling no higher than setup-scoped functional evidence.

This gate remains `NotRun` until the independent source, preregistration,
artifacts, and signed report are available. Agreement with Astral's negative
results validates the conclusion that the tested setups do not support the
strong claims; it does not create a positive introspection result.
