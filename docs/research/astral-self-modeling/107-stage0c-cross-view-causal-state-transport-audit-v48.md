# Astral cross-view causal-state-transport audit V48 — design memo

State slice: `astral-stage0c-cross-view-causal-state-transport-audit-v48`.

Date: 2026-08-28.

Status: `DesignOnly / ExecutionNotAuthorized / AssessmentNotAuthorized`.

## Rationale and authorization boundary

V47 was rejected because its localization criterion and causal assignment
assumptions were not executable. V48 is a new measurement audit, not a V47
repair or a V46 parameter variation. It asks a narrower question:

> Does a fixed internal state carrier transport a known task-state change from
> a donor context into a held-out receiver context, with the same signed effect
> under two independently encoded views and no comparable effect from matched
> null or input-only controls?

The scientific object is causal state transport, not introspection. The state
is externally defined by a sealed finite state graph; the model's internal
representation is only a candidate carrier of that state. A positive result
would be bounded to this actor, operator, task family, and corpus identity.
It would not establish self-modeling, privileged self-access, consciousness,
Stage 0C, Stage 1, benchmark evidence, or production readiness.

This memo authorizes only design and independent review. It does not authorize
model or corpus acquisition, GiveMeANode jobs, node creation, model loading,
source changes, runner implementation, qualification, fit/tune measurement,
assessment, artifact-root creation, or evidence-ledger mutation. A separate
implementation authorization is required after acceptance.

## Theory and causal variables

For family `q`:

- `S` is a four-valued task state from a sealed finite state graph;
- `V` is one of two independently generated semantic encodings of `S`;
- `X` is the complete observed context, including the task and one encoding;
- `H` is the fixed internal carrier site receiving the state transport;
- `P` is the state-transport intervention, with `P=1` replacing the receiver
  carrier by a state-matched donor carrier and `P=0` reinserting the receiver's
  own captured carrier through the same seam (the access-null);
- `N` is a separate matched generic-output/norm control, with `N=1` replacing
  the receiver carrier by a state-shuffled donor and `N=0` reinserting the
  receiver's own carrier;
- `Y` is a predeclared signed state-choice logit margin at the response token;
- `M` is a measurement view of the captured carrier used only for fit-time
  state decoding and prediction; and
- `D` is the donor/receiver state direction.

The causal assumptions are fixed before data are opened:

1. **Consistency:** the observed output equals the potential output for the
   executed `P,V,D` condition, and the donor tensor is copied only at the
   declared layer, position, pass, and dtype.
2. **Assignment and positivity:** each family has every required `P,V,D`
   condition, and the order of those conditions is generated by a seeded,
   label-independent counterbalancing rule. Every condition has nonzero
   execution probability before exclusions.
3. **Timing:** donor capture occurs in a completed forward pass; the receiver
   patch is applied exactly once before downstream computation at `H`; no
   post-intervention activation is supplied to a predictor.
4. **No interference:** a trial reads no mutable state from another trial;
   model weights, tokenizer, runtime, code, and RNG policy remain fixed and no
   training or adapter update occurs.
5. **Stable unit:** a family is the same sealed task state, context identity,
   state graph edge, and response mapping across all cells. Missing cells cause
   family exclusion by a predeclared rule before any effect summary is read.
6. **View separation:** `V=1` and `V=2` use independent generators,
   codebooks, templates, and surface realizations. Neither view is a
   deterministic transformation of the other, and neither shares target
   effects or intervention labels with the other.

The causal graph is:

```text
S ─────► X ─────► H ─────► Y
│        │        ▲
│        └──────► Y
│                 │
└────► donor H ───┘

V ─────► X                 P ─────► H
M ◄──── H                  N ─────► H   (matched null only)
```

`P` and `N` act on `H`, not directly on `Y`. The direct `X -> Y` path is the
input-only rival. `M` is measurement data, not a causal parent of the model
outcome. `N=1` uses a fixed, label-independent permutation of donor families
within each view and direction, then source-to-receiver norm matching; it is
not selected from effects and it carries no state-matched donor label.

## Primary estimand: cross-view causal state transport

For a family, view, and direction, let `Y(p,v,d)` be the signed response-token
margin under the declared condition. The signed transport effect is:

```text
Delta(v,d) = Y(P=1,v,d) - Y(P=0,v,d)
```

The reciprocal-direction, cross-view estimand is:

```text
tau_CST = E[ (Delta(1,+) - Delta(1,-)
             + Delta(2,+) - Delta(2,-)) / 4 ]
```

The primary unit is the sealed family. `tau_CST` is a paired causal
difference-in-differences over donor direction and independent encoding view.
It is not a correlation, a probe score, or a post hoc activation-to-effect
association. The direction contrast cancels a generic donor-output shift; the
two views test transportability of the same state effect.

The directly measured outcome is fixed before data acquisition:

```text
Y = logit(response token for the receiver's declared state)
    - logit(response token for the paired alternate state)
```

The response tokens, state ordering, token position, and margin orientation
are part of the implementation manifest. No scale switching is permitted.

## Localization estimand and exact gate

The localization target is one theory-selected carrier, not a search over
layers. The implementation contract must use the fixed deep-to-shallow pair
`source_layer=26`, `destination_layer=12`, the final state-anchor position,
one additional forward pass, source-to-destination norm matching, and
`alpha=0.10`. These values follow the 40-layer actor geometry (approximately
65% to 30% depth) and a small fixed transport perturbation; they are not
selected from V46, fit effects, or assessment effects.

For every view and donor direction, define the potential outcome
`Y(p,n,v,d)` where exactly one of `p` or `n` may equal `1`. `P=0,N=0` is the
identity-reinsertion cell. `P=1,N=0` is the state-matched donor transport
cell. `P=0,N=1` is the state-shuffled, source-to-receiver norm-matched generic
donor cell. The `P=1,N=1` combination is forbidden and is rejected by the
panel validator. Define:

```text
Delta_CST(v,d)  = Y(1,0,v,d) - Y(0,0,v,d)
Delta_null(v,d) = Y(0,1,v,d) - Y(0,0,v,d)
```

The localization estimand is:

```text
lambda_local = E[Delta_CST - Delta_null]
```

The fixed localization gate is a lower 95% document-cluster bootstrap bound
for `lambda_local >= 0.10` response-margin units and a standardized lower
bound `>= 0.20` relative to the fit-only SD of the family contrast. Both
conditions are required. The matched generic-output control must not exceed
the same signed state contrast by more than `0.05` margin units.

There is one localization hypothesis and one carrier, so no layer-selection
multiplicity correction is needed. The two view-specific contrasts are
components of the single primary estimand. Any additional layer, wrapper,
position, alpha, or operator would require a new authorization.

## Cross-view invariance and recoverability

The state map is fit only on fit families using a fixed four-class linear
decoder with a fixed feature budget. `V1` and `V2` are decoded in both
directions using the same locked map. Recoverability passes only if the lower
95% bootstrap bound for balanced accuracy exceeds `0.25 + 0.10 = 0.35` on
tune families in each direction. The minimum four-state requirement and
threshold are fixed before data are opened.

Cross-view effect invariance is a secondary scientific gate, not a selection
criterion. Define:

```text
gamma_view = E[Delta(1,+) - Delta(1,-)]
             - E[Delta(2,+) - Delta(2,-)]
```

An assessment candidate must have a two-sided 90% equivalence interval for
`gamma_view` contained in `[-0.10, +0.10]` response-margin units. This test is
declared before effects and is not replaced by a favorable single-view result.

## Fresh data identity

The external artifact root must contain a new panel with no V39-V47 corpus,
document, family, anchor, template, activation, effect, predictor, or result
reuse. Project Gutenberg may supply the external context component, but prose
is context only and is not treated as state ground truth. A separate sealed
state generator supplies the ground truth.

Each family contains:

1. a new public-domain context document and byte digest;
2. a four-state edge from a new finite state graph;
3. two independently seeded semantic encodings of that state;
4. a receiver context and a donor context differing only in the declared
   state edge and its controlled surface realization;
5. a fixed state-choice response mapping; and
6. all required natural, transport, reciprocal, null, norm-matched, shuffled,
   constant, exact-copy, activation-only, text-only, and input-only controls.

Fit, tune, and assessment are disjoint by document, author, exact and
normalized text, codebook seed, generator seed, template, state graph, state
edge, and counterfactual mapping. The validator performs exact and normalized
duplicate checks before model execution. Each split has an independent digest
and a complete file census.

## Power, reliability, and missingness

The planning effect is `d=0.35`, standardized by the SD of the family-level
`tau_CST` contrast before document clustering. Planning assumes four families
per document, document ICC `0.20`, two-sided alpha `0.05`, and 90% power. The
cluster design effect is `1.60`; adjusted counts are rounded up before
conversion to documents. This table is not an observed result:

| Standardized d | Independent family units | Cluster-adjusted family equivalents | Documents before attrition | Documents with 20% attrition |
|---:|---:|---:|---:|---:|
| 0.35 | 86 | 138 | 35 | 44 |

Before assessment, the implementation must replace this approximation with a
sealed four-cell simulation using the actual covariance, four condition cells,
document cluster structure, missingness rule, and fixed `tau_CST`. Assessment
cannot open below the simulated count achieving 90% power across the
predeclared ICC sensitivity range `[0.10, 0.30]`.

Reliability uses independent-process repeats and alternate-view repeats. The
fixed gates are:

- lower 95% bound for `ICC(A,1)` >= `0.80` for the state decoder score;
- lower 95% bound for `ICC(A,1)` >= `0.80` for the family transport effect;
- sign stability >= `0.80` across the independent repeats;
- no more than 5% missingness per required cell; and
- no complete family with a missing cell enters an effect analysis.

The repeat count, bootstrap resamples, confidence-interval method,
missingness handling, and variance decomposition are sealed before fit data
are read. The primary uncertainty unit is the document cluster.

## Controls, locking, and retention

The unchanged V46 control contract remains mandatory: activation-only,
text-only, exact-copy, shuffled, constant, and matched. V48 adds transport
access-null and matched-energy/norm controls. Text-only and input-only
predictors receive every field visible in `X` and no hidden state or effect
label. All controls use the same family cells, feature budget, fit rule, and
held-out split.

The order is fixed:

1. validate fresh custody, actor/runtime identity, and qualification;
2. fit the state decoder and predictor on fit families only;
3. emit and digest tune predictions before generating tune effects;
4. freeze feature map, operator, metric, controls, thresholds, and retention;
5. obtain independent review against that configuration;
6. open assessment only after a valid review receipt; and
7. generate assessment effects, retain aggregates only, and run the independent
   validator.

The external immutable result root may retain only digests, counts, aggregate
effects and predictions, uncertainty intervals, reliability summaries, stop
codes, lock receipts, review receipts, and validator receipts. Raw prompts,
activations, logits, generated text, per-token telemetry, transcripts,
credentials, and PII are prohibited.

## Falsifiers and classifications

Stop without adaptive retry on any parity, custody, shape, repeatability,
nonzero-reach, duplicate, split, state-recoverability, localization,
reliability, control, power, lock, review, retention, or validator failure.

Permitted classifications are:

1. `InstrumentFeasibility` — apparatus qualifies; no causal candidate is
   established.
2. `DevelopmentNoCandidate` — apparatus qualifies, but locked transport,
   invariance, reliability, control, or held-out gates fail.
3. `BoundedCausalStateTransportResult` — all preregistered transport,
   localization, cross-view, reliability, control, prediction-lock, review,
   retention, and validation gates pass for the named actor and panel.

The third classification is limited to causal state transport for the named
actor, operator, task family, and corpus. It does not establish introspection,
causal self-modeling, Stage 0C, Stage 1, benchmark evidence, or production
readiness. V46 remains permanently closed. V82 remains isolated and blocked;
Neural Chameleon artifacts cannot be used as V48 inputs.
