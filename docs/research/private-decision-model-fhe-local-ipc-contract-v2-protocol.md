# Private Decision Model FHE Local IPC Contract V2

State slices: `private-decision-model-fhe-local-ipc-contract-v2` and
`global-experiment-assurance-lifecycle-v1`. Frozen dependency slice:
`private-decision-model-fhe-inference-v1`.

## Purpose and claim ceiling

This is a fresh, local-only continuation for strict JSON/Base64 validation at
the FHE client/server process boundary. V1 remains byte-for-byte frozen. V2
reuses only its deterministic synthetic scorer, fixture, Python dependency
lock, and Concrete runtime identity.

The maximum claim is
`LocalDevelopmentSyntheticFHEIPCContractQualificationV2`: the V2 local
synthetic IPC parser rejects malformed and ambiguous envelopes and one bounded
local FHE execution preserves the frozen synthetic scores. This is not a
cryptographic security, hostile-process isolation, remote-service, real-data,
benchmark, or production claim. External review is not part of this slice;
reviewer status remains `EXTERNAL_REVIEW_UNAVAILABLE` for the separate V1
review packet.

## Frozen question and hypothesis

The question is whether V2's exact IPC contract rejects duplicate JSON keys,
non-finite constants, unknown or missing fields, incorrect types or counts,
empty payload fields, malformed Base64, and non-canonical Base64 before
deserialization, while accepting canonical envelopes for the fixed V1
workload.

The hypothesis is that a closed-world parser for both worker requests and
client responses makes the process boundary fail closed for these malformed
synthetic envelopes without changing V1 source, scorer, fixture, lock, or
claim.

## Workload and budgets

- Data: the V1 deterministic synthetic fixture only; no user, external, or
  held-out research data.
- Shapes: eight evaluation requests; four options per request; six signed
  integer features per option in `[-8, 8]`; 128 synthetic training rows and
  12 synthetic calibration requests remain unchanged.
- Tests: pure local parser tests over fixed literal byte strings, including
  duplicate-key and malformed-envelope cases; one subprocess rejection case
  must stop before attempting to load a server bundle.
- FHE qualification: at most one local end-to-end run; at most eight encrypted
  request tensors; one client-spec invocation, one FHE evaluation invocation,
  and one malformed-envelope process check that must stop before bundle load;
  each worker invocation has a 900-second timeout, while the parser-only
  process check has a 30-second timeout.
- Network/spend: no provider, remote worker, network service, or paid
  execution. Dependency setup may use only the existing V1 locked environment
  and, if unavailable, the pinned official PyPI dependency boundary already
  authorized for V1.
- Custody: synthetic values, keys, circuit bundle, serialized ciphertexts,
  and encrypted responses exist only in process memory or a system temporary
  directory and are removed at completion. Retain aggregate counts and
  digests only; do not retain raw IPC envelopes.

## Fixed contract and controls

The worker request has exactly two fields: `evaluation_keys` and
`encrypted_arguments`. The fixed V2 qualification requires exactly eight
non-empty canonical Base64 strings in `encrypted_arguments` and one non-empty
canonical Base64 string for `evaluation_keys`. The worker response has exactly
one field, `encrypted_results`, containing exactly eight non-empty canonical
Base64 strings. Duplicate keys are rejected at every JSON object depth;
non-standard JSON constants are rejected. No additional fields are accepted.

Positive controls use canonical envelopes generated by the local runner.
Negative controls cover duplicate keys, non-object roots, invalid JSON,
non-finite constants, missing and extra fields, incorrect field types,
wrong request/result counts, empty strings, invalid Base64, and Base64 with
non-canonical pad bits. The subprocess negative control verifies a malformed
request fails before server-bundle loading and writes no result to stdout.
The one FHE qualification retains the V1 score-equality and ranking checks.

## Stop conditions and nonclaims

Stop this identity on any parser-control failure, V1 fixture or dependency
drift, encrypted/clear score mismatch, ranking mismatch, timeout, or failure
to remove temporary artifacts. Do not retune a failed control or reuse a
changed source under this V2 packet. No external review, secure transfer,
review task, real data, remote service, paid run, public release, or claim
above the named ceiling is authorized.

Any later change to parser semantics, FHE runtime, scorer, fixture, or claim
requires a fresh state slice and packet. V1 remains immutable historical
evidence; V2 results do not rewrite or promote its review status.
