## Scientific object

controller, model, pending, carryover, and resource state. It is compared with
fixed batch-one SGD on the same ordered stream and byte-identical initial
checkpoint. Each episode is paired, arm execution order is randomized by a
sealed hash transcript, one block is washed out, and the primary endpoint is
the mean post-washout loss difference. The controller can read only the
previous block; current-block outcomes cannot affect action assignment.

Qualification streams are predictable signal plus noise, feature-relevance
drift, delayed reward, sparse events, long horizon, and pure noise. Real
execution, if later authorized, requires fresh disjoint NoisyMNIST and
event-camera or sensor families with fit/tune/assessment separation.
