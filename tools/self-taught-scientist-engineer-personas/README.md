# The Self-Taught Scientist / Engineer

State slice: `self-taught-scientist-engineer-persona-site-v1`.

A local, static concept site inspired by the structure of the linked
ScientistTwo research page. It translates the supplied persona framing into an
interactive field guide for switching between calculated and unhinged modes
without turning either mode into a doctrine.

The page is intentionally conceptual. It does not read or write repository
research artifacts, run models, make scientific claims, or create evidence.

Run from the repository root:

```text
python3 -m http.server 4173 --directory .
```

Open:

```text
http://localhost:4173/tools/self-taught-scientist-engineer-personas/
```

The page has no third-party dependencies and no network asset requirements.
