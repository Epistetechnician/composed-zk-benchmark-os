# Composed Desktop

Electron Release 0 is a minimal React/TypeScript shell for a future local
operator surface.

State slice: `electron-release-0-desktop-shell`.

## Scope

- Displays a capability catalog from a read-only main-process handler.
- Displays the explicit unavailable state of the local replay adapter seam.
- Uses the platform's versioned `platform-ipc.v1` request/response envelope,
  including canonical payload digests and strict success/error shapes.
- Exposes only two typed methods through a secure contextBridge preload.
- Keeps the renderer isolated from Node and Electron APIs.

The Rust sidecar is not implemented here. `src/adapters/local-replay.ts` is a
data-only seam returning an unavailable status. No native process execution,
command execution, repository access, or external research code belongs in
this release.

## Layout

- `src/main.ts` owns the window, IPC validation, and fixed read-only handlers.
- `src/preload.ts` exposes the narrow `window.desktopApi` surface.
- `src/ipc/contract.ts` contains shared types, canonical JSON hashing, and pure
  envelope validation aligned with the platform `src/ipc.rs` contract.
- `src/adapters/local-replay.ts` defines the future Rust adapter boundary.
- `src/renderer/` contains the functional catalog and unavailable-state UI.
- `docs/ipc-contract-v1.md` is the versioned integration contract.

## Local commands

Run from `apps/desktop` after dependencies are installed:

```sh
pnpm install
pnpm test
pnpm typecheck
pnpm start
```

This repository currently has no root pnpm workspace manifest, so Release 0 is
intentionally self-contained and does not add root workspace metadata. Do not
commit `node_modules`, `.vite`, `out`, `dist`, or a lockfile generated by
another package manager. A future root workspace can include this package if
the repository adopts one deliberately.

## Integration notes

The future Rust integration should implement `LocalReplayAdapter` behind the
existing `createLocalReplayAdapter` seam. It must first specify process custody,
artifact/input provenance, lifecycle, failure mapping, and authorization; this
scaffold does not imply that a local replay is runnable or that any benchmark
evidence exists.
